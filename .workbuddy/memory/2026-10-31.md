## README 补界面预览截图

截图流程（可复用，环境坑都踩过了）：

1. `node server.js`（8765）连真实设备；另起 `/tmp/shot-proxy.js`（8790）转发到 8765，只对 JSON/HTML 做字面量替换，把 SN / IMEI / ICCID / SSID / MAC / 公网 IP / 内网主机 IP 换成演示值，`"percent"` 统一改 76%。用代理截图的目的是既保留真实数据结构，又不把真实标识写进公开仓库。
2. `/tmp/shot.js` 走 CDP：`spawn` 无头 Chrome（`--no-sandbox`）→ `Target.attachToTarget` → `Emulation.setDeviceMetricsOverride`（390×900 dsf2 / 1280×900 dsf1）→ `Page.captureScreenshot` + `captureBeyondViewport`。可见首屏尺寸靠 setDeviceMetricsOverride，**不要**用 `--window-size` + `--screenshot`（前者在 headless 下布局按 ~800 宽算，右边缘会被切）。
3. 首页速率图依赖 `history.rx/tx`（60 点 × 5s = 5 分钟才铺满），截图前用 `Runtime.evaluate` 注入 60 点波形并 `drawChart()`，尾段做衰减以免和随后 push 的真实点形成断崖。
4. `cwebp -q 92` 输出到 `docs/screenshots/`，4 张共 444 KB（PNG 原图 900 KB）。

- **沙箱坑**：Chrome 前台启动必被 SIGTERM（137、连 echo 都不输出）；必须 `run_in_background: true` 跑。
- 顺带发现：bash 的 `grep` 对 `public/index.html` 匹配不到内容（当作二进制/编码问题），要改用 ripgrep（Grep 工具）；`sed -i ''` 在本机也报 "No such file or directory"，改用 Edit 工具。
